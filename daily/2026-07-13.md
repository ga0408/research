## 1. Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading
- [ ] [2607.08964](https://arxiv.org/abs/2607.08964) · upvotes: 53 · 소속: Tencent Hunyuan · repo: [zli12321/LHTB](https://github.com/zli12321/LHTB)

이 논문은 장기 지속 터미널 작업에서 에이전트의 한계를 측정하는 Long-Horizon-Terminal-Bench 벤치마크를 제안합니다. 실험 재현, 소프트웨어 엔지니어링, 멀티모달 분석, 상호작용 게임, 과학 컴퓨팅 등 9개 카테고리에 걸쳐 46개의 장기 지속 작업으로 구성되어 있습니다. 각 작업은 참조 솔루션이나 시뮬레이션 엔진을 갖춘 Terminal-Bench 스타일로 설정하면서도 세분화된 채점 하위 작업으로 분해되어, 최종 목표 달성 여뿐 아니라 중간 진행 상황과 부분 점수를 dense reward로 포착합니다. 작업은 일반적으로 수백 에피소드와 수 분에서 수 시간의 실행을 필요로 하며, 15개의 최신 모델 평가에서 평균 9.9M 토큰, 약 231 에피소드, 85.3분의 실행 시간이 소요되었습니다. 가장 강력한 모델도 부분 보상 임계값 0.95에서 pass@1 15.2%, 완전 보상 임계값 1.0에서 10.9%에 그쳤고, 모델 평균은 각각 4.3%와 1.7%였습니다.

GenCeption은 사전학습된 비디오 생성 확산 백본을 활용해 텍스트 지시에 따라 깊이, 표면 법선, 카메라 자세 추정, 표정 기반 referring segmentation, 3D 키포인트 예측 등 다양한 비전 작업을 수행하는 feed-forward 인식 모델입니다. 여러 작업에서 최신 성능을 달성했으며, DepthAnything3, SAM3, D4RT, VGGT-Omega, Sapiens 등 전문 모델과 맞먹거나 능가합니다. 비디오 생성 사전학습은 V-JEPA나 Video MAE 같은 대안 사전학습 방식보다 동일 조건에서 우수하며, 7배에서 500배 적은 학습 데이터로도 D4RT나 VGGT-Omega 수준의 성능을 보이는 데이터 효율성을 입증했습니다. 또한 합성 인간 비디오로만 학습한 모델이 실제 영상과 동물, 로봇 같은 분포 외 범주로 일반화되는 새로운 특성도 보입니다.

## 4. KronQ: LLM Quantization via Kronecker-Factored Hessian
- [ ] [2607.07964](https://arxiv.org/abs/2607.07964) · upvotes: 17 · 소속: University of Southern California · repo: [Intelligent-Computing-Lab-Panda/KronQ](https://github.com/Intelligent-Computing-Lab-Panda/KronQ)

이 논문은 재학습 없이 대규모 언어 모델(LLM)을 압축하는 post-training quantization(PTQ) 기법인 KronQ를 제안합니다. 기존 2차 PTQ 방법인 GPTQ 등은 출력 채널이 모두 동일하게 기여한다고 가정하고 입력 활성화 통계만 사용하는데, KronQ는 그래디언트 공분산을 정량화 파이프라인에 도입해 이 가정을 깨뜨립니다. Kronecker-분해 Hessian 근사 하에 정량화 손실은 활성화와 그래디언트 공분산에 공동으로 의존하며, KronQ는 이를 양방향 비일관성 처리와 새로운 민감도 지표를 통한 층간 혼합 정밀도 할당이라는 두 수준에서 활용합니다. 양방향 비일관성 처리는 기존 입력 측 무작위 회전을 그래디언트 공분산을 이용해 출력 차원으로 확장해 가중치 크기 분산을 줄입니다. LLaMA-3-70B에서 2비트 가중치 전용 정량화 시 GPTQ와 GPTAQ는 발산하거나 퇴화된 정량화를 만들어내 WikiText-2에서 2,000 이상의 perplexity를 보인 반면, KronQ는 7.93 perplexity를 달성했습니다.

## 5. Trust Region Policy Distillation
- [ ] [2607.04751](https://arxiv.org/abs/2607.04751) · upvotes: 17 · 소속: HKUSTGZ

이 논문은 불안정하고 분산이 큰 On-Policy Distillation(OPD)을 안정적인 학습 패러다임으로 바꾸는 Trust Region Policy Distillation(TOP-D)을 제안합니다. TOP-D는 동적으로 proximal teacher를 구성해 이론적으로 그래디언트 분산을 제어하며, 전역 수렴 분석과 단조 개선 상한을 통해 학습 역학의 안정성과 신뢰성을 수학적으로 형식화합니다. 수학적 추론 작업에서 TOP-D는 학습 안정성, 샘플 효율성, 최종 성능을 크게 향상시키며 추가 계산 오버헤드가 전혀 없습니다. 이는 기존 OPD 패러다임을 대체할 수 있는 유망한 방법입니다.

## 6. From RGB Generation to Dense Field Readout: Pixel-Space Dense Prediction with Text-to-Image Models

- **키워드**: text-to-image models, dense prediction, VAE latent space, DiT, task LoRA, token-local linear head, FLUX-Klein, trimap-free matting, KITTI depth, referring segmentation, normals, saliency, pose

이 논문은 텍스트-이미지 모델의 사전학습을 dense prediction 작업에 직접 활용하는 ReChannel 방법을 제안합니다. 기존 방식이 깊이, 법선, 마스크 등의 주석을 RGB로 학습한 VAE 잠재 공간에 인코딩해 이미지 형태로 생성하는 것과 달리, ReChannel은 사전학습된 DiT(diffusion transformer)가 이미지 평면 위에서 패치-토큰-패치 격자를 이미 형성하고 있다는 점을 이용해 각 토큰을 작업 고유의 픽셀 공간 패치로 매핑합니다. VAE 인코더는 유지하되 타깃 측 디코더는 제거하고, 동결된 DiT에 task LoRA를 적용한 뒤 공유된 토큰-로컬 선형 헤드로 각 토큰을 p x p x K_t 픽셀 공간 패치로 변환하며, 약 33K 파라미터만 추가하고 공간 혼합은 없습니다. FLUX-Klein을 사용해 6개 dense prediction 작업과 10개 이상의 벤치마크에서 평가한 결과, trimap-free matting, KITTI depth, referring segmentation에서 최신 기록을 세우고 법선, 현저성 추정, 자세 추정에서도 경쟁력을 보였습니다. 동일 4B 설정에서 latent decode 기반 편집 방식보다 2.48배 빠르면서도 더 정확해, 생성 모델의 출력 인터페이스를 그대로 물려받지 않고도 dense 인식이 생성 사전학습의 이점을 누릴 수 있음을 보여줍니다.

## 13. VaseMuseum: Digital Intelligent Museum for Ancient Greek Pottery

이 논문은 고대 그리스 도자기를 위한 지능형 디지털 박물관 프레임워크 VaseMuseum을 제안합니다. VaseMuseum은 상호작용형 가상 박물관과 VaseAgent를 결합해 2D 이미지와 3D 유물을 다루며, 멀티모달 인식, 3D 인지 추론, 외부 지식 검색, 추론 시점 신뢰성 제어를 지원합니다. 출처 수준 제어는 권위 있는 웹과 박물관 지식 원천에서 다양하고 검증 가능한 근거를 선별하고, 응답 수준 제어는 생성된 주장을 근거 풀과 대조해 근거가 불충분하거나 상충될 때 중립적이고 근거에 기반한 답변을 유도합니다. 또한 학습이 필요 없는 GRPO 스타일 선택 메커니즘으로 유효한 인용과 보정된 확신을 가진 응답을 선호하도록 합니다. 실제 디지털 박물관 시뮬레이션 실험에서 VaseMuseum은 인용 유효성을 높이고 지식 집약적 질의에서 환각을 줄이며 모호한 상황에서 더 중립적인 답변을 생성합니다.
